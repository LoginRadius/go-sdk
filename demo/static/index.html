Passwordless login

No password: a one-time code is emailed or texted to an existing user, then verified here to start a session. A tenant with MFA enabled still enforces its second factor afterward, same as Log in above.

Second factor required

The login returned a challenge. Its token is held in a separate short-lived cookie — a session cookie will not open these routes.

WebAuthn needs a secure context. http://localhost counts, so this works as shipped; over plain HTTP on any other host the browser will refuse. The same applies to logging in below.
